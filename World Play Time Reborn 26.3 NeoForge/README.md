# World Play Time Reborn (NeoForge, Minecraft 26.3)

Displays the world's play time and world size in the world selection menu.

This is a fork of the original [World Play Time](https://modrinth.com/mod/world-play-time) mod, which is no longer receiving updates for new versions of Minecraft.

- [Modrinth](https://modrinth.com/mod/world-play-time-reborn)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/world-play-time-reborn)

## Building

Requires JDK 25.

```bash
./gradlew build
```

The built jar can be found in `build/libs/`.

> Note: `neo_version` in `gradle.properties` is set to `26.3.0.0-beta` as a placeholder — NeoForge for Minecraft 26.3 has not been published yet. Update it to the actual version from https://projects.neoforged.net/neoforged/neoforge once released.
